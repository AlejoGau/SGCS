# Plan 07-03: UX de contrato y cálculo dinámico

**Phase:** 07-facturador-dinamico-cantidad-automatica  
**Type:** Implementation  
**Depends on:** 07-02  
**Requirements:** [AUTO-02, AUTO-03, AUTO-04]  
**JIRA:** MGF-DEV-09

## Outcome

Hacer que el contrato deje de editar `Quantity` manual cuando corresponda y que la facturación resuelva la cantidad desde las cuentas asociadas.

## Target Files

- `softguard.workspace/packages/local/common/src/view/ContratoItemFormView.js`
- `softguard.workspace/packages/local/common/src/controller/ContratoItemFormController.js`
- `softguard.workspace/packages/local/common/src/model/ContratoItemModel.js`
- `softguard.workspace/packages/local/common/src/controller/ContratoCuentaGridController.js`
- `database/_Desktop/StoredProcedures/MG_ContratoAFactura.sql`

## Tasks

1. Bloquear u ocultar `Quantity` manual para productos automáticos.
2. Resolver el conteo desde las cuentas asociadas al contrato.
3. Mantener la lógica actual de precios/listas.
4. Validar compatibilidad con contratos no automáticos.

## Acceptance Criteria

- La cantidad facturada coincide con la relación real del contrato.
- El cambio no altera el comportamiento de contratos manuales.
